## module nopfunit

This module has been used in project RIVM.OPS and an earlier version in MARIN.ComFLOW.
This reopsitory does not yet have a CI or examples or manual.  Those should be added 
when nopfunit is used in a project.

The module `m_log_call` generates (unit) tests for subroutines in a system that 
is running, has test-inputs, but nu unit tests.  It helps you recreate calls
that occur in the existing calculations, and compare the results to the results of
the current version of the program. 

Again, CI, examples and manual are needed.
